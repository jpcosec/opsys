# Human Attention Drawer

`desk/drawer/attention/` holds captured inbox items that are not ready to become tasks, issues, questions, atoms, docs, or specs.

Use it for:

- likely fixtures or test artifacts that need a human deletion decision
- vague notes that need clarification before routing
- low-signal suggestions that should not keep the project inbox occupied

## Rule

Items in this folder are not active work. A human should either promote each item into a durable drawer/desk surface or delete it intentionally.

Do not leave reviewed items here after the decision is made.
