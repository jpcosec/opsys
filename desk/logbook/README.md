# Workflow logbook

This directory stores deskops-central workflow log entries.

Scope rules:

- record deskops workflow and harness changes here
- use this surface for runtime, CLI, routing, validation, and closeout changes in the central tool
- do not use this directory for downstream project-local workflow notes
- when a central change was triggered by a local repo, name that repo as context but keep the entry focused on deskops itself
