# Promotion flattens structured source sections into task fields

## Answer

Inbox-to-drawer promotion parses task-shaped headings (Rationale, Goal, Scope, Implementation Path, Validation, Done When) out of the free-form note and flattens them into the drawer candidate task fields. Drawer-to-active is explicit authoring with deskops add task --from-drawer <selector>, which records the origin in TaskDoc.from_drawer and keeps the drawer file rather than copying its sections.
