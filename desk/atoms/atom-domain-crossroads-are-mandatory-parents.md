# Domain crossroads are mandatory parents

## Answer

Every prefix of a domain:<a.b.c> tag must have a crossroad document (CrossroadDoc) whose written content describes what hangs below that path. The system is forced to write the parent before it can describe its children, so a knowledge base stays ordered: the domain tree is navigable and every branch explains itself instead of being a bare label.
