# Materializations are projections, not read surfaces

## Answer

A rendered document, an agent prompt file or a diagram is a projection of its source atoms. Reading it back as the source flattens the layers: the projection carries formatting and framing the atoms do not, so decisions made from it inherit both. Read the atoms; regenerate the projection.
