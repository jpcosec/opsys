# Stale state causes agent hallucination

## Answer

Retaining legacy code, commented blocks, and untracked stale files actively degrades LLM agent performance by feeding them obsolete constraints and invalid contextual signals. The space must represent only the active and present state to avoid semantic drift and context overload.
