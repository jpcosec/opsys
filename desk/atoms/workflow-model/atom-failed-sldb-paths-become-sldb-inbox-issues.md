# Failed SLDB paths become SLDB inbox issues

ID: atom-failed-sldb-paths-become-sldb-inbox-issues
5WH1+: when

## Answer

When an expected SLDB query, write, edit, validation, or model path fails or is missing, the gap should be captured in the sibling SLDB repo inbox before building a deskops-specific workaround.
