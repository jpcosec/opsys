# Rendered diagrams are projections

ID: atom-rendered-diagrams-are-projections
5WH1+: how_not

## Answer

Agents should not treat generated Mermaid, PlantUML, SVG, or rendered diagrams as canonical source when a structured diagram spec should exist.
