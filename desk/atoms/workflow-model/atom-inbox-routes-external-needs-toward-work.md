# Inbox routes external needs toward work

ID: atom-inbox-routes-external-needs-toward-work
5WH1+: how

## Answer

Inbox exists for external project coordination: another project can place questions, requests, or bugs there, and those entries are triaged into issues, drawer items, responses, or eventually active tasks.
