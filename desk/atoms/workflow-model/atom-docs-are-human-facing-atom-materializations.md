# Docs are human-facing atom materializations

ID: atom-docs-are-human-facing-atom-materializations
5WH1+: what

## Answer

Docs are materializations when they compose selected atoms into a human-facing explanation, guide, or manual while preserving traceability back to the atoms that supply the durable claims.
