# Workflow vocabulary separates knowledge and work

ID: atom-workflow-vocabulary-separates-knowledge-and-work
5WH1+: what

## Answer

Deskops workflow nouns separate durable knowledge, transient execution context, routed work, automation rules, and explanatory projections so agents do not treat every Markdown file as the same kind of obligation.
