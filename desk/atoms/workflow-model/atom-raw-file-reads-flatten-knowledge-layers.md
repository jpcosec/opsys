# Raw file reads flatten knowledge layers

ID: atom-raw-file-reads-flatten-knowledge-layers
5WH1+: how_not

## Answer

Agents should not treat every Markdown file as equivalent raw prose, because atoms, specs, docs, diagrams, tasks, pills, inbox notes, and generated projections have different roles and source-of-truth rules.
