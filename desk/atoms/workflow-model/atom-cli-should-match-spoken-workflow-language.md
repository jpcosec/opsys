# CLI should match spoken workflow language

ID: atom-cli-should-match-spoken-workflow-language
5WH1+: how

## Answer

The deskops CLI should be as close as possible to spoken workflow language, exposing commands that match how users describe routing, asking, promoting, executing, checking, closing, and querying work.
