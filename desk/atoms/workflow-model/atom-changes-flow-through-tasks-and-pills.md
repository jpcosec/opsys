# Changes flow through tasks and pills

ID: atom-changes-flow-through-tasks-and-pills
5WH1+: how

## Answer

Repository modifications should be implemented through a combination of routed tasks and bound pills so work has explicit scope, context, validation, and guardrails before code, docs, specs, or workflow artifacts change.
