# SLDB graph owns relations between knowledge surfaces

## Answer

Relations between artifacts belong in the SLDB graph (`sldb.api.graph`): the graph should represent how code, docs, specs, tests, diagrams, tasks, pills, libraries, languages, patterns, linters, and consumers connect to each other and to atoms. KGDB was retired and merged into SLDB.
