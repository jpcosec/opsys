# KGDB owns relations between knowledge surfaces

ID: atom-kgdb-owns-relations-between-knowledge-surfaces
5WH1+: what

## Answer

Relations between artifacts belong in KGDB: the graph should represent how code, docs, specs, tests, diagrams, tasks, pills, libraries, languages, patterns, linters, and consumers connect to each other and to atoms.
