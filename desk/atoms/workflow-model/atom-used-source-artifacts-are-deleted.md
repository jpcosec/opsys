# Used source artifacts are deleted

ID: atom-used-source-artifacts-are-deleted
5WH1+: when

## Answer

When inbox, drawer, or other source artifacts are promoted or consumed into active tasks, atoms, docs, specs, code, tests, or commits, the original source file should be deleted rather than marked with terminal statuses such as promoted or stable.
