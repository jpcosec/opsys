# Deskops automates repeated workflow obligations

ID: atom-deskops-automates-repeated-workflow-obligations
5WH1+: why

## Answer

Deskops exists to automate repeated workflow obligations such as routing tasks, binding context, running validation, committing changes, deleting completed tasks, and preserving knowledge flow so agents do not spend context remembering mandatory process steps.
