# Codebase surfaces generate atom candidates

ID: atom-codebase-surfaces-generate-atom-candidates
5WH1+: how

## Answer

Large codebase surfaces can be divided into internal sections and crossed with labeled edges. Each edge, with its role, target kind, and answered question, can be read as a candidate atom request.
