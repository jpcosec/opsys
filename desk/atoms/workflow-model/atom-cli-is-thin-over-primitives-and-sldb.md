# CLI is thin over primitives and SLDB

ID: atom-cli-is-thin-over-primitives-and-sldb
5WH1+: how

## Answer

The deskops CLI should expose workflow nouns and operations while delegating state rules to primitives and modeled document read/write/edit behavior to SLDB rather than becoming a second implementation of either layer.
