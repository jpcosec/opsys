# Clean code reduces knowledge drift

ID: atom-clean-code-reduces-knowledge-drift
5WH1+: why

## Answer

Code should follow strict clean-code principles so implementation remains modular, readable, and self-explanatory, leaving atoms and materializations to explain durable concepts, constraints, and rationale that code cannot express by itself.
