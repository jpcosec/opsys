# Atoms are the stable documentation core

ID: atom-atoms-are-stable-documentation-core
5WH1+: what

## Answer

Atoms are the stable core of project documentation; every durable doc, spec, README, diagram, test explanation, or implementation rationale should either be an atom or a materialization of selected atoms.
