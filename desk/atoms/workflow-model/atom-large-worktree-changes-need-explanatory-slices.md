# Large worktree changes need explanatory slices

ID: atom-large-worktree-changes-need-explanatory-slices
5WH1+: how

## Answer

When a workspace accumulates many related edits, the changes should be grouped into reviewable explanatory slices so git history and closeout can show which conceptual move each slice represents.
