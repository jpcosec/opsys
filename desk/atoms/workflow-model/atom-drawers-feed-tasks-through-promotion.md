# Drawers feed tasks through explicit authoring

## Answer

Future, uncertain, or loosely shaped work enters `desk/drawer/` as features, issues, questions, or other lax artifacts, then becomes active execution only when a person or agent authors a routed task from it with `deskops add task --from-drawer`. There is no drawer-to-active promotion command; the drawer file is kept for manual cleanup.
