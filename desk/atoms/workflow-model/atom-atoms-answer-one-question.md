# Atoms answer one raw question

ID: atom-atoms-answer-one-question
5WH1+: what

## Answer

An atom is curated knowledge that answers exactly one raw 5WH1+ question: what, why, how, how_not, when, where, or for_whom. It should not carry outgoing relations to every place it is used.
