# Materialization contracts bind source output validation

ID: atom-materialization-contracts-bind-source-output-validation
5WH1+: what

## Answer

A materialization contract should bind source atoms, output artifact kind, output path or identity, transformation intent, and validation checks so the artifact can be regenerated, reviewed, or marked stale intentionally.
