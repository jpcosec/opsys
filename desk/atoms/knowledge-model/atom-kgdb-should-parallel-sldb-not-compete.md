# KGDB should parallel SLDB not compete

ID: atom-kgdb-should-parallel-sldb-not-compete
5WH1+: why

## Answer

KGDB should run alongside SLDB as a graph persistence and traversal layer, while SLDB remains the owner of modeled Markdown contracts, semantic indexes, and document read/write/edit operations.
