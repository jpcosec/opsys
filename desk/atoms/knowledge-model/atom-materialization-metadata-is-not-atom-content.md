# Materialization metadata is not atom content

ID: atom-materialization-metadata-is-not-atom-content
5WH1+: how_not

## Answer

Atoms should remain small knowledge claims; use-site metadata such as where an atom is rendered, validated, or referenced belongs to the materializing artifact or an index, not inside the atom body.
