# Source file relations make knowledge actionable

ID: atom-source-file-relations-make-knowledge-actionable
5WH1+: why

## Answer

A knowledge graph becomes operationally useful when it links durable knowledge units to the source files that implement, validate, expose, configure, or violate them.
