# Raw signals need distillation before formalization

ID: atom-raw-signals-need-distillation-before-formalization
5WH1+: when

## Answer

Conversations, task notes, bugs, review comments, incidents, and code discoveries should become atoms before they are treated as stable docs, specs, diagrams, or implementation contracts.
