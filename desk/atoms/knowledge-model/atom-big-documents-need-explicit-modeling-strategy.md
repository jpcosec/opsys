# Big documents need explicit modeling strategy

ID: atom-big-documents-need-explicit-modeling-strategy
5WH1+: why

## Answer

Large human-facing documents need an explicit SLDB modeling strategy because some should stay shallow composed bodies, while others need typed sections, references, validation, or materialization metadata.
