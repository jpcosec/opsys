# KGDB is graph substrate not reasoner

ID: atom-kgdb-is-graph-substrate-not-reasoner
5WH1+: what

## Answer

KGDB should be used as the dumb graph persistence and query substrate for deskops knowledge relations, while semantic judgment, workflow rules, and ontology reasoning remain in deskops, SLDB, ontology, or later reasoning layers.
